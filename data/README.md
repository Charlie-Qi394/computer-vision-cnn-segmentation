# Data

Large datasets are not included in this repository.

Suggested inputs:
- Classical CV demos: user-provided images, or sample images from permitted libraries such as `skimage.data`.
- Classification: CIFAR-100 or CIFAR-100-style image classification data.
- Segmentation: Pascal VOC-style image and mask data, downloaded separately under its original license.

Keep downloaded datasets outside git, for example:
```text
data/raw/
data/processed/
```

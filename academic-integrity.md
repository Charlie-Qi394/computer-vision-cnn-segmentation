# Academic Integrity Note

This repository is a reconstructed portfolio version of university learning work.

It intentionally excludes:
- Assignment briefs and marking rubrics.
- Submitted reports, PDFs and cover sheets.
- Student identifiers.
- Restricted or course-provided datasets.
- Model checkpoints and generated binaries.
- Any file that would let the repository act as a direct assignment submission.

The purpose of this repository is to demonstrate technical skills in computer vision, Python implementation, model evaluation and portfolio communication.
